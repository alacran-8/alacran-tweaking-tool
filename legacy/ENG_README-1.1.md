# Alacran Tweaking Tool

**Alacran Tweaking Tool** is a Windows optimization tool written in pure **Batch (.bat)**.

It is designed to improve:
- Gaming performance
- System responsiveness
- Input latency
- Overall Windows behavior for gamers

No malware. No background services. No hidden tasks.

---

## ⚙️ What does this tool do?

This batch script applies various Windows tweaks, including:
- Power plan optimizations
- Disabling unnecessary Windows services
- Registry-based performance tweaks
- Gaming-related system adjustments
- Basic cleanup and configuration changes

All commands are standard Windows commands and can be reviewed manually.

---

## 🛡️ VirusTotal & False Positives

Some antivirus engines may flag this tool as **suspicious**.  
This is a **false positive**.

### Why this happens:
- The script modifies registry values
- Administrative commands are used
- Batch files are often abused by malware (heuristic detection)
- The file is unsigned (no code-signing certificate)
- Low reputation (new or niche tool)

There is **no malicious code** in this script.

You are encouraged to:
- Open the `.bat` file in Notepad
- Review every command
- Run it only if you understand what it does

---

## ▶️ How to use

1. Download the `.bat` file from the **Releases** section
2. Right-click the file → **Run as administrator**
3. Follow the on-screen instructions
4. Restart your system after completion
